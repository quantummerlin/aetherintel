What is Gemini 3.5 Flash?

Released on 19 May 2026, Gemini 3.5 Flash is Google's latest production model — and the first Flash to cross the threshold into genuine reasoning capability. Where previous Flash models were defined primarily by speed and low cost, 3.5 Flash is explicitly positioned as a near-Pro model that runs at Flash latency. Google describes it as "highly optimized for coding proficiency and parallel agentic execution," a shift that reflects how AI workloads have evolved: less single-shot generation, more multi-step agent pipelines.

The model's version number carries weight. The jump from 3.1 to 3.5 is not a minor patch — it signals a meaningful capability uplift within the same generational family. 3.1 Flash was a strong, capable mid-tier model; 3.5 Flash is positioned as what you'd reach for before committing to Pro pricing. At $1.50 input / $9.00 output per 1M tokens, it sits significantly above Flash Lite ($0.25/$1.50) but close to Gemini 2.5 Pro ($1.25/$10.00) — the pricing alone signals Google's ambitions for where this model competes.

What the .5 Version Bump Actually Means

Google's versioning convention has been consistent: a .5 release represents a substantial capability upgrade rather than a minor refinement. Gemini 2.5 was a significant step over 2.0 across every benchmark Google tracked; 3.5 follows the same logic within the 3.x generation. The key capability additions over Gemini 3.1 Flash are threefold.

First, reasoning token support. The include_reasoning and reasoning parameters are now supported, meaning the model can run a chain-of-thought scratchpad before producing its final answer — identical to the mechanism in Gemini 2.5 Pro. This is not available on any Flash Lite model and was limited on 3.1 Flash. Reasoning tokens are billed at the output rate ($9.00/1M), so prompts that trigger extended thinking cost more, but the quality uplift on complex tasks can be substantial.

Second, agentic optimisation. Google specifically calls out "parallel agentic execution" as a design target. This means the model is tuned to perform well inside tool-calling loops, maintain context coherence across multi-step operations, and reason correctly about intermediate results — exactly the failure modes that plague smaller models when used as agents.

Third, coding proficiency. The explicit emphasis on coding puts 3.5 Flash in direct competition with models like GPT-5 ($1.25/$10.00) and Claude Sonnet 4.6 ($3.00/$15.00) for code generation workloads. Google's Gemini Pro series has long been strong on code; 3.5 Flash brings that Pro-calibre coding capability to a Flash-speed, mid-tier price point.

Reasoning Tokens — When to Enable Them

Reasoning tokens in Gemini 3.5 Flash work identically to the Pro tier: when the include_reasoning parameter is enabled, the model generates a private chain-of-thought scratchpad before producing its final response. The scratchpad is not returned to the caller by default, but it informs the quality of the final answer. Reasoning tokens are billed at the same rate as output tokens ($9.00/1M).

The decision of whether to enable reasoning depends entirely on the task. For most classification, extraction, summarisation, and routine generation tasks, reasoning adds cost and latency without improving the output — the model's direct-answer capability is sufficient. Reserve reasoning for tasks where intermediate steps matter: complex debugging, multi-constraint code generation, analytical problems with non-obvious answers, and multi-hop reasoning chains.

Cache Pricing Changes the Economics

At $0.15 per 1M tokens for cache reads (10× cheaper than fresh input), Gemini 3.5 Flash becomes substantially more economical for applications with repeated system prompts or static context. An agent loop that passes a 50,000-token codebase as context on every turn saves 90% of input costs on cached tokens after the first call. For production deployments with stable context, the effective input price can drop well below the headline $1.50/1M.

Built-in Web Search at $0.014 Per Call

Gemini 3.5 Flash includes native web search grounding as a supported parameter — the same capability that has powered Google's AI Overviews in Search. When web search is invoked, the model retrieves and cites current web results, letting it answer questions beyond its January 2025 knowledge cutoff without any external retrieval infrastructure.

At $0.014 per search call, it is not free, but for applications where freshness matters — market data, news summarisation, product research, support ticket resolution with current documentation — the cost is negligible compared to building and maintaining a separate retrieval pipeline. For a typical web-grounded query, the total cost is: input tokens + output tokens + $0.014. A 2,000-token exchange with one search call runs roughly $0.022 all-in.

This stands in contrast to Perplexity Sonar Pro ($1.00/$1.00 + search), which is purpose-built for retrieval but priced higher per token. For teams that primarily use the model for generation but occasionally need live web data, 3.5 Flash's integrated search is the more economical path.

Full Five-Modality Input

Like all Gemini models, 3.5 Flash accepts text, images, audio, video, and files (PDFs, structured documents) in the same request. The architecture treats all five input types uniformly — there is no special preprocessing or routing required on the caller's side. Audio is billed at $3.00/1M tokens (versus $1.50/1M for text and images), reflecting the higher processing cost of audio understanding.

In practice, this means a single API endpoint can handle a product catalogue image, a customer voice recording, a PDF invoice, and a natural-language instruction in one request. The unified interface simplifies pipeline design substantially compared to routing different media types to different models — and 3.5 Flash's near-Pro intelligence means the multimodal outputs are genuinely high-quality rather than just "technically supported."

Reading the Benchmark Response

The near-Pro positioning is visible immediately. Where a typical Flash model might describe SQL as "ACID-compliant storage," Gemini 3.5 Flash unpacks all four ACID properties in a parenthetical without being asked. The "window functions" call-out in the SQL strengths list is a detail many mid-tier models omit — it signals genuine familiarity with the SQL feature set rather than pattern-matching on surface-level keywords.

The banking example is tightly argued: it doesn't just say "use SQL for finance" — it specifies the PostgreSQL SERIALIZABLE isolation level as the correct tool and names the failure mode it prevents (split-brain money movement). That level of prescriptive technical accuracy is more characteristic of Pro-tier responses. For a model at $0.0054 per benchmark call, the depth-to-cost ratio is the headline number.

The MAX_TOKENS cutoff mid-sentence on the NoSQL section is a reminder that the 600-token ceiling is an artificial constraint — in production with a higher output budget, the response completes fully. The structural scaffold (starred callouts, strength/weakness bullets, concrete named examples) is clean throughout.

Final Assessment

Gemini 3.5 Flash is the most interesting model Google has released in the mid-tier category. The combination of reasoning token support, agentic tuning, native web search, 1M context, five-modality input, and near-Pro coding capability at $1.50/$9.00 per 1M is a genuinely differentiated offering. No direct competitor at this price point checks all those boxes simultaneously.

The benchmark confirms what the positioning promises: the analytical depth and technical precision in its SQL/NoSQL response reads more like Gemini 2.5 Pro than a Flash model. For teams running agentic workflows, coding assistants, or complex multimodal pipelines where Flash Lite has started hitting its ceiling, Gemini 3.5 Flash is the natural upgrade — and at the pricing, it doesn't demand a budget rewrite to justify.

The one watch point is output cost. At $9.00/1M output — identical to Gemini 2.5 Pro — verbose generation workloads will see the same bill as the Pro tier. For applications where output volume is high and task complexity doesn't require the 3.5 jump, Flash Lite or Gemini 2.5 Flash remain better economic choices. But for intelligence-first use cases where you previously grudgingly paid Pro prices, Gemini 3.5 Flash offers a compelling reason to revisit the stack.
