# Aether Intel

**AI Signal · Always On**

Aether Intel is a curated AI intelligence publication covering AI agents, tools, models, safety, and the business of AI. Built and maintained with AI agents.

## Live Site

**[ai.quantummerlin.com](https://ai.quantummerlin.com)**

## Structure

```
├── articles/       # Long-form articles (116+)
├── models/         # AI model profiles (55+)
├── css/            # Production stylesheet
├── js/             # Core JS (nav, ticker, search, models feed)
└── images/         # Hero images and assets
```

## Sections

- **News** — AI news, analysis, and opinion
- **Labs** — AI laboratory atlas (OpenAI, Anthropic, Google, etc.)
- **Agents** — AI agent guides and workflows
- **Models** — OpenRouter model browser
- **Skills** — Downloadable AI capability prompts

## Tech

- Static HTML/CSS/JS — no build step
- Deployed via Cloudflare
- Content managed through GitHub
- PWA-enabled with service worker
